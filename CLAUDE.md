# Правила для агента (читать в начале каждой сессии)

Эта папка - постоянная память между сессиями. Правила обязательные.

## В начале сессии

1. Прочитать `01_Главный_контекст/КОНТЕКСТ.md` целиком: короткая выжимка - кто пользователь, цели, текущие задачи, действующие решения.
2. Детали брать из `02_База/`: блок, затем оглавление (заметка с именем папки), затем нужная заметка.
3. Большие заметки не читать целиком: сначала поиск по словам, потом только нужный кусок.
4. Подгрузить память ошибок: `memory/MEMORY.md` - индекс правил, которые появились после ошибок.

## Как класть новое в базу

- **Одна заметка - одна вещь** (человек, место, вещь, программа, организация, событие, цель). Перед созданием - поиск: нет ли её уже (в том числе по `aliases`).
- **Заметка лежит там, чем вещь является по сути;** оттуда, где используется, - ссылка.
- **Связь пишется в событии:** кто, где, чем, зачем. Остальные заметки видят её через обратные ссылки.
- **У каждого факта - источник** («со слов пользователя, дата», файл, ссылка). Догадка помечается как догадка.
- Типы, свойства и связи - только из `04_Система/Словарь.md`. Новое слово - сначала туда.
- После добавления заметок: `node 04_Система/скрипты/обновить-оглавления.js` - пересоберёт оглавления.

## Как вести главный контекст

- Компактно: выжимка на 1-2 экрана, не архив.
- Всё, что требует предыстории, - в отдельную заметку в `02_База/`, в контексте одна строка со ссылкой.
- Устаревшее не копить, а править. История по дням - в `04_Система/Журнал.md`, не в контекст.
- Сказанный пользователем факт сразу записывать: незаписанного для следующей сессии не существует.

## Память ошибок

Каждую ошибку записать отдельным файлом в `memory/` по шаблону `memory/_шаблон.md` и строкой в `memory/MEMORY.md`: что случилось, **почему** это важно, **как применять** в будущем. Перед похожим действием - свериться с памятью.

## Проверка

- «Работает» значит проверено на данных: открыть результат и сверить с исходником.
- «Попадает само», «готово», «отправлено» - говорить только после проверки.

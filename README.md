# claude-memory-kit

Каркас базы знаний, с которой Claude Code (или другой агент) **помнит контекст между сессиями** и **не повторяет свои ошибки**. Это обычная папка Markdown-файлов, её удобно открывать в Obsidian.

Я пользуюсь такой системой каждый день: в моей базе 300+ заметок. Здесь только каркас и правила, без моих данных.

## Зачем

Без памяти каждая сессия с ИИ начинается с нуля: заново объясняешь, кто ты и что уже решили, а агент уверенно достраивает то, чего не знает. С этим каркасом агент:

- в начале сессии читает короткий главный контекст, за деталями ходит в нужную заметку;
- кладёт новое по правилам: одна заметка - одна вещь, у каждого факта источник;
- записывает каждую свою ошибку правилом и сверяется с ним в следующий раз.

## Структура

```
CLAUDE.md                          правила для агента (Claude Code читает его сам)
01_Главный_контекст/КОНТЕКСТ.md    выжимка на 1-2 экрана
02_База/                           блоки: Люди, Работа, ... (оглавление = заметка с именем папки)
04_Система/Словарь.md              типы заметок, свойства, связи
04_Система/Журнал.md               история по дням
04_Система/шаблоны/                шаблоны человека и события
04_Система/скрипты/обновить-оглавления.js   пересобирает оглавления
memory/                            память ошибок: правило = файл + строка в MEMORY.md
```

## Как начать

1. Скопируйте папку, откройте её в Claude Code (и при желании в Obsidian).
2. Заполните `01_Главный_контекст/КОНТЕКСТ.md` - минут десять.
3. Работайте как обычно: агент сам кладёт факты в базу, а правила после ошибок - в `memory/`.
4. После добавления заметок: `node 04_Система/скрипты/обновить-оглавления.js` (нужен Node.js).

Заметки-примеры в `02_База` выдуманные, удалите их.

Мои рабочие скрипты: [ai-tools](https://github.com/iatakvijy/ai-tools).
